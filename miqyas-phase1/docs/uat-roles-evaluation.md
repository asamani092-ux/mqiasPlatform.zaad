# نموذج تقييم الأدوار والصلاحيات — منصة مِقياس | جمعية الزاد

مرجع تقييم UAT حسب الأدوار. الصفحة التفاعلية: `/uat` → تبويب **الأدوار والصلاحيات**.

تفعيل: `ENABLE_UAT=true` (بيئة التجربة فقط).

## القاعدة الذهبية

جرّب بكل دور على حدة، وسجّل **الرؤية** / **الوصول** / **النطاق**.

التقييم: `غير مجرّب` | `مطابق` | `يحتاج تحسين` | `خلل`

## 1) الموظف

| 5 | رفع شاهد في المسودة | يُقبل الرفع · العدّ يعكس الشواهد النشطة فقط | غير مجرّب |  |
| 6 | التقديم يُقفل الإدخال | الحالة SUBMITTED · الحقول مقفلة · رسالة منع عند محاولة الكتابة عبر API/واجهة | غير مجرّب |  |
| 7 | منع حذف الشاهد بعد التقديم | رفض 400 — الحذف فقط في DRAFT أو بعد الرفض | غير مجرّب |  |
| 8 | حلقة الرفض — ظهور ملاحظات القسم | حالة قابلة للتعديل · صندوق «ملاحظات القسم / المشرف» يظهر السبب والحقول/الشواهد المرفوضة | غير مجرّب |  |

| 12 | جولة مغلقة تمنع التقديم والرفع وتسمح بالمسودة | المسودة تنجح · التقديم والرفع يُرفضان · الاعتماد النهائي يبقى للمشرف | غير مجرّب |  |
