# قبول م1 — مطابقة الوثيقة والواجهة

تاريخ الجولة: بعد نشر `92fc7f3`. المرجع: [platform-governing-principles.md](./platform-governing-principles.md).

| متطلب | الحالة | ملاحظة |
|-------|--------|--------|
| لا نظام موازٍ للكتابة | مطابق | `/api/strategy/catalog` POST/PUT → 410؛ الكتالوج عرض |
| أوسمة تغذية مستقلة | مطابق | مربعات في `/admin/kpis`؛ `/strategic` يفلتر `feedsStrategic` |
| إسناد واحد | مطابق | `/admin/assign` يحدّث المتطلب والمؤشر؛ الحوكمة تعرض `assignedOwnerName` |
| وسم مرحلة لكل أداة | مطابق | شارات التنقّل + `ToolPhaseBar` من `phase-registry` |
| مسارات القياس مطوية | مطابق | `collapsible` + `defaultOpen: false` |
| لا حذف مسارات | مطابق | مسارات الأصل باقية حسب الدور |
| وثائق أوسمة م1 (بدل v2) | أُصلح | خارطة الطريق محدّثة |
| نموذج إدارة المؤشرات `grid-2` | أُصلح | حقول أساسية بعمودين؛ ملاحظات بعرض كامل |

## قبول وظيفي (تحقق آلي + يدوي)

| خطوة | آلي | يدوي على الإنتاج |
|------|-----|------------------|
| أوسمة أصل/م1 في القائمة | اختبارات `nav-strategy` | مشرف / مدير |
| طي مسارات القياس | اختبارات التنقّل | مشرف |
| مؤشر استراتيجي+حوكمة | منطق `resolveFeedFlags` | إنشاء من `/admin/kpis` |
| حوكمة فقط خارج `/strategic` | فلتر الصفحة + اختبار الأوسمة | مشاهدة المسارين |
| إسناد → `/my` | مسار API الإسناد قائم | إسناد موظف |
| الكتالوج بلا حفظ | 410 على الكتابة | محاولة غير متاحة في الواجهة |

بعد الدمج: أكمل العمود اليدوي على بيئة Coolify ثم انتقل لتخطيط م2 فقط عند الاكتمال الأخضر.
