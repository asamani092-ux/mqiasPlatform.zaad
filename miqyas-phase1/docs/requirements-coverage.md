# مطابقة المتطلبات بالأدوات الحالية

مرجع النص المعتمد: توصيات رئيس اللجنة والأستاذة شروق. دور رئيس اللجنة مؤجّل.

## أصل القياس

| المتطلب | الأداة | الحالة |
|---------|--------|--------|
| إدخال الشاهد | `/my` | مطابق |
| اعتماد مبدئي ونهائي | `/dept-follow` و`/approvals` | مطابق |
| لوحات القياس | `/dashboard` و`/executive` | مطابق |
| استراتيجي وتشغيلي وإنذار وانحراف | المسارات المقابلة | مطابق |
| المعرفة المؤسسية | `/knowledge` | مطابق كأداة أصل؛ النص لم يفصّل متطلباتها |

## مكتب الاستراتيجية والحوكمة

| المتطلب | الأداة | الحالة |
|---------|--------|--------|
| متطلبات الحوكمة مع المؤشرات في شاهد واحد | `/admin/kpis` ثم `/my` | مطابق |
| عرض الكتالوج بلا كتابة موازية | `/strategy` | مطابق |
| دخول مدراء الإدارات ورؤساء الأقسام وموظفي الاستراتيجية | صلاحيات مكتب الاستراتيجية | مطابق |
| إضافة وتعديل المؤشرات والمتطلبات | `/admin/kpis` | مطابق |
| رزنامة قابلة للتعديل | `/calendar` | مطابق |
| مسار الحوكمة | `/governance` | مطابق، والشاهد من إدارة المؤشرات |
