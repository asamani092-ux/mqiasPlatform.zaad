# قائمة تقييم أدوات — مِقياس | جمعية الزاد

الصفحة التفاعلية (بيئة التجربة فقط): **`/uat`**

- تبويب **حسب الأدوات** (هذا الملف) — منظّم بالشاشات.
- تبويب **حسب الأدوار** — مكمّل؛ انظر [`uat-roles-checklist.md`](./uat-roles-checklist.md) لاختبار الصلاحيات وسلسلة الاعتماد end-to-end.

تفعيل عبر `ENABLE_UAT=true` في `.env` — في الإنتاج اتركها `false`.

التقييمات (أدوات): `غير مجرّب` | `يعتمد` | `يحتاج تحسين`

زر **نسخ التقرير** يولّد Markdown للنموذج النشط (أدوات أو أدوار).

تصنيف الملاحظة (اختياري): `UI ناقص` · `بيانات/تدفق` · `صلاحيات` · `أداء/أخطاء` · `نص/RTL` · `أخرى`

دخول التجربة: `http://localhost:3000/login` — `ADMIN_EMAIL` / `ADMIN_PASSWORD` من `.env`
