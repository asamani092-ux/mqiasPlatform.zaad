# قبول م3 — لجنة المراجعة

| متطلب | الحالة | ملاحظة |
|-------|--------|--------|
| دور في إدارة المستخدمين | مطابق | `AUDIT_COMMITTEE` |
| اجتماعات ومحاضر وقرارات | مطابق | `/committee/meetings` `/minutes` `/decisions` |
| لوحة مشتركة | مطابق | `/committee` من بيانات م2 دون تعديل مسارات القياس |
| تقارير صادرة بلا أوراق عمل | مطابق | الصندوق يعرض `ISSUED` فقط؛ `manageAuditPapers` مرفوض للجنة |
| رفع خارجي داخلي | مطابق | `ExternalAuditUpload` من اللجنة أو فريق المراجعة |
| لا حساب مراجع خارجي | مطابق | لا دور خارجي |
