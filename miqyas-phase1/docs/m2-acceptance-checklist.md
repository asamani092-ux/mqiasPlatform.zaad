# قبول م2 — المراجعة الداخلية (الأساس)

المرجع: [platform-governing-principles.md](./platform-governing-principles.md) · [strategy-office-roadmap.md](./strategy-office-roadmap.md).

| متطلب | الحالة | ملاحظة |
|-------|--------|--------|
| لا نظام موازٍ للقياس | مطابق | مسارات `/my` والاعتماد والانحراف بلا حذف |
| دور صريح في إدارة المستخدمين | مطابق | `INTERNAL_AUDITOR` في `Role` + `ROLE_VALUES` / `ROLE_LABEL` |
| وحدات تحت `/audit` | مطابق | ملخص، خطة، مهام، ملاحظات، تقارير، أوراق عمل |
| وسم م2 في التنقّل والسجل | مطابق | `phase-registry` + شارات القائمة |
| أوراق عمل `INTERNAL_ONLY` | مطابق | `can.manageAuditPapers` — التنفيذي مرفوض |
| تقارير بلا كشف أوراق العمل | مطابق | التنفيذي يرى التقارير الصادرة فقط |
| إغلاق ملاحظة بعد الإجراءات | مطابق | رفض الإغلاق إن بقيت إجراءات غير منجزة (مع إغلاق قسري) |
| لا دور لجنة / لا مراجع خارجي | مطابق | خارج النطاق (م3) |

## قبول آلي

| خطوة | اختبار |
|------|--------|
| الدور في `ROLE_VALUES` | `nav-audit` / `rbac` |
| أوراق العمل محجوبة عن التنفيذي | `can.manageAuditPapers(EXECUTIVE) === false` |
| تنقّل المراجع | قسم «المراجعة الداخلية» فقط |
| تنقّل التنفيذي بلا أوراق عمل | `/audit/papers` غير موجود في القائمة |
